本ドキュメントは、提出済み卒論ドラフト・発表資料・7月18日メモの内容を統合し、論理構造を整理した完全版のまとめとして再構成したものである。卒論本文の補強、発表資料の裏付け、そして最新の修正方針を一つの体系にまとめている。

1. 研究の目的と全体構造

本研究は、伝言ゲーム型の「直線的伝搬」における誤情報の劣化過程を数理モデルとして記述し、さらに人間の認知特性や個人差を取り込むことで、より現実的なモデルへと拡張することを目的とする。

研究の3段階構成

最小モデル（通信理論）：人間をノイズのある通信路とみなし、誤り率 r による指数的劣化を記述。

認知心理学モデル（バイアス導入）：人間の意思決定を支配する「常識バイアス」を最上位に置く階層型モデルへ拡張。

ベータ分布＋LLM実証（データサイエンス）：個人差を確率分布で表現し、LLMマルチエージェントでパラメータを同定。

2. 基本モデル：直線的伝搬の数理構造

2.1 モデルの設定

情報は 1 → 2 → 3 → … → N と一直線に伝達される。

各ステップで誤りが確率 r で発生する。

誤りは独立に発生すると仮定する。

2.2 数式

[ P(N) = (1-r)^N ]

2.3 含意

誤り率が 10% でも 10 人経由で正確さは 35% に低下。

劣化は 指数関数的であり、人数が増えるほど急速に情報が崩壊する。

2.4 半減期

[ N_{1/2} = \frac{\ln(0.5)}{\ln(1-r)} ]

例：

r = 5% → 約 13.5 回

r = 10% → 約 6.6 回

r = 20% → 約 3.1 回

誤り率のわずかな違いが、伝達可能距離を大きく左右する。

3. 拡張モデル1：自己修復率 s の導入

3.1 動機

基本モデルでは「一度誤った情報は永遠に誤ったまま」という非現実的な仮定がある。実際には、受け手が

他人に確認する（P₁）

ネットで調べる（P₂） などの行動により、情報を修復することがある。

3.2 数式

[ P(N) = {(1-r) + r s}^N ]

3.3 含意

実効誤り率は r(1-s) に低下する。

r=10%, s=80% の場合、半減期は 34 回まで伸びる（基本モデルの約5倍）。

自己修復は誤情報の蓄積を大幅に抑制する。

4. 拡張モデル2：ベータ分布による誤り率の揺らぎ

4.1 動機

誤り率は個人差・状況差が大きい。固定値 r では現実を表現できない。

4.2 数式

誤り率 r を Beta(α, β) に従う確率変数とする。

期待値としての正確性： [ P(N) = \frac{B(\alpha, \beta+N)}{B(\alpha, \beta)} ]

4.3 含意

平均誤り率が同じでも、ベータ分布モデルは固定モデルより 正確さが高く残る。

これは「誤り率の低い人が連続する幸運なチェーン」が一定割合で存在するため。

4.4 正しい解釈（7月18日メモの修正）

ベータ分布は 一本道の生存確率ではなく、

社会全体で並列に発生する多数の伝搬チェーンの中で、どれだけ生き残るか（裾の長さ） を表すマクロ指標である。

5. 認知心理学モデル：バイアスを最上位に置く階層型意思決定

5.1 動機

従来の「自己修復」は、追加情報なしに元に戻るという論理破綻があった。

5.2 モデル構造

個人のバイアス強度を b とする（0〜1）。

行動選択の確率：

他人に聞く：(P_1 = (1-b) w_1)

ネットで調べる：(P_2 = (1-b) w_2)

調べずに自己判断：(P_3 = b + (1-b) w_3)

5.3 実効誤り率

[ R = r \Big[ 1 - (P_1 s_{human} + P_2 s_{net} - P_3 b) \Big] ]

5.4 含意

バイアスが強いほど、誤情報は加速的に増幅される。

偏見の強いコミュニティではデマが長寿化しやすい。

6. LLMによるマルチエージェント・シミュレーション

6.1 目的

パラメータ（b, w₁, w₂, w₃）の実測値を得る。

モデルの妥当性を計算機内で検証する。

6.2 方法

A. ペルソナ実験

LLMに多様な属性を与え、噂話を提示し、行動選択を観察する。 → パラメータを統計的に推定。

B. 実動伝言ゲーム

LLM同士で伝言ゲームを実行し、意味的乖離を Embedding で測定。 → 実効誤り率 R を実測。

7. 発表会での想定問答（防衛戦略）

Q1. 「自己修復は不自然では？」

→ 自己修復は記憶復元ではなく、**外部情報との同期（検索・他者確認）**を抽象化したもの。

Q2. 「ベータ分布は一本道に使えないのでは？」

→ 単一チェーンではなく、社会全体の多数のチェーンの期待生存割合を表す。

Q3. 「パラメータの根拠は？」

→ LLMマルチエージェントで データ駆動的に同定可能。

8. 結論

直線的伝搬は (P(N)=(1-r)^N) で記述できる。

誤り率がわずかでも、情報は指数的に劣化する。

自己修復・バイアス・個人差を導入すると、現実の噂話のしぶとさを説明できる。

LLMによる実証を組み合わせることで、現代的なデータサイエンス論文として完成度が高まる。
