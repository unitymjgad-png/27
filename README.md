# 1. 研究の目的と全体構造

本研究は、伝言ゲーム型の**直線的情報伝搬**における誤情報の劣化過程を数理モデルとして記述し、さらに人間の認知特性や個人差を取り込むことで、現実社会に近い情報伝達モデルへ拡張することを目的とする。

## 研究の3段階構成

### 第1段階：最小モデル（通信理論）

人間を**ノイズを含む通信路**として扱い、誤り率 \(r\) のみで情報劣化を記述する。

### 第2段階：認知心理学モデル（バイアス導入）

人間の意思決定を支配する**常識バイアス**を最上位概念として導入し、情報修正行動を説明する。

### 第3段階：ベータ分布＋LLM実証（データサイエンス）

個人差を確率分布で表現し、LLMマルチエージェント実験によりパラメータを推定・検証する。

---

# 2. 基本モデル：直線的伝搬の数理構造

## 2.1 モデルの設定

以下を仮定する。

- 情報は

  ```
  1 → 2 → 3 → … → N
  ```

  と一直線に伝搬する。

- 各伝達で誤りが確率 \(r\) で発生する。
- 誤りは各段階で独立に発生する。

---

## 2.2 数式

情報が正確なまま伝わる確率は

\[
P(N)=(1-r)^N
\]

となる。

---

## 2.3 含意

例えば誤り率が

- \(r=0.1\)

であれば

\[
P(10)=0.9^{10}\approx0.35
\]

となり、10人経由すると正確性は約35%まで低下する。

つまり情報劣化は**指数関数的**に進行する。

---

## 2.4 半減期

正確性が50%になる伝達回数は

\[
N_{1/2}
=
\frac{\ln(0.5)}
{\ln(1-r)}
\]

で求められる。

### 例

|誤り率|半減期|
|-------|------|
|5%|約13.5回|
|10%|約6.6回|
|20%|約3.1回|

誤り率のわずかな違いでも、伝達可能距離は大きく変化する。

---

# 3. 拡張モデル1：自己修復率 \(s\) の導入

## 3.1 動機

基本モデルでは

> 一度誤った情報は永久に誤ったまま

という非現実的な仮定が存在する。

実際には受信者は

- 他人へ確認する
- インターネットで検索する

などの行動によって情報を修正する。

この効果を**自己修復率**として導入する。

---

## 3.2 数式

修復率を \(s\) とすると

\[
P(N)=\left[(1-r)+rs\right]^N
\]

となる。

---

## 3.3 含意

実効誤り率は

\[
r_{\mathrm{eff}}
=
r(1-s)
\]

となる。

例えば

- \(r=0.1\)
- \(s=0.8\)

では

\[
r_{\mathrm{eff}}=0.02
\]

となり、半減期は約34回まで延長される。

つまり自己修復は誤情報の蓄積を大幅に抑制する。

---

# 4. 拡張モデル2：ベータ分布による誤り率の揺らぎ

## 4.1 動機

実際の誤り率は

- 個人差
- 状況差
- 知識量
- 注意力

などにより一定ではない。

そこで

\[
r
\]

を確率変数として扱う。

---

## 4.2 数式

誤り率を

\[
r
\sim
\mathrm{Beta}(\alpha,\beta)
\]

とすると

期待正確性は

\[
P(N)
=
\frac
{B(\alpha,\beta+N)}
{B(\alpha,\beta)}
\]

で与えられる。

ここで

- \(B(\cdot)\)：ベータ関数

である。

---

## 4.3 含意

平均誤り率が同じでも

固定値モデルよりも

ベータ分布モデルの方が

長期的に正確性が高く残る。

これは

**誤り率の低い伝搬経路**

が一定割合存在するためである。

---

## 4.4 正しい解釈（7月18日修正版）

ベータ分布モデルは

一本道の情報伝搬を表すものではない。

表現しているのは

> 社会全体で同時並行に存在する多数の伝搬チェーン

であり、

その中で

**どれだけ情報が生き残るか**

というマクロな割合を示すモデルである。

---

# 5. 認知心理学モデル：バイアスを最上位に置く階層型意思決定

## 5.1 動機

従来モデルでは

「追加情報なしに元へ戻る」

という論理的矛盾が残っていた。

そこで

人間の行動そのものをモデル化する。

---

## 5.2 モデル構造

個人のバイアス強度を

\[
b
\]

とする。

### 行動選択

#### 他人へ聞く

\[
P_1=(1-b)w_1
\]

#### ネット検索

\[
P_2=(1-b)w_2
\]

#### 自己判断

\[
P_3=b+(1-b)w_3
\]

ここで

\[
w_1+w_2+w_3=1
\]

である。

---

## 5.3 実効誤り率

\[
R
=
r
\left[
1-
\left(
P_1s_{\mathrm{human}}
+
P_2s_{\mathrm{net}}
-
P_3b
\right)
\right]
\]

---

## 5.4 含意

バイアスが強いほど

- 他人へ確認しない
- ネット検索しない
- 自己判断が増える

ため

誤情報は加速度的に蓄積する。

その結果

偏見の強いコミュニティでは

デマが長寿化しやすいことを説明できる。

「本研究において『情報空間』とは、社会的関心が高く客観的事実の確認が困難な状況下において、マクロに存在する無数の伝搬チェーンを通じて情報が意味的に変容・生存していく動的な環境と定義する。この空間は、全人類の複雑なコミュニケーションを網羅するものではなく、エージェントの内的バイアスと外部同期行動、および伝搬経路ごとの誤り率のばらつき（ベータ分布）によって制約された確率論的なモデル空間である。」

# 第X章 実測データに基づく誤り率の近似とベータ分布へのフィッティング実験

## X.1 実験の目的と背景
本研究の第5章で定式化したベータ分布モデルでは、誤り率 \(r\) のばらつきを確率分布として扱ったが、そのパラメータ（\(\alpha, \beta\)）は仮設定の数値に基づいていた。そこで本実験では、人間が情報を処理・伝達する際の実測データを取得し、実際の誤り率の分布を近似することを目的とする。

特に、人間が情報を受け渡す際に生じる「不要な解釈の混入」や「文脈の変質（ノイズ）」を意図的に誘発するため、元の文章の意味を保ったまま文字数を1.5倍に引き延ばして書き換えさせる「冗長化伝達タスク」を課す。被験者には、統計および医療を専門的に学んできた鈴鹿医療科学大学の学生集団（\(n\)名）を選定し、専門教育を受けた集団における情報の生存特性を明らかにする。

## X.2 実験方法
1. **被験者**: 鈴鹿医療科学大学 医用工学部 データサイエンス学科等の学生 \(n\) 名。
2. **提示刺激**: 医療統計または医療ニュースに関する300字程度の標準的な文章（原文 \(A\)）を提示する。
3. **タスク**: 被験者に対し、「原文の意味や重要な要素を一切変えずに、文字数を元の1.5倍（約450字）に書き換えて次の人に伝える文章（記述文 \(B\)）を作成せよ」と指示する。

## X.3 意味の保存度（正確性）の定量化アプローチ
記述された文章が、原文の意味をどれだけ保持しているか（正確性）を客観的に評価するため、大規模言語モデル（LLM）の埋め込みモデル（Embedding）を用いたセマンティック類似度（意味的類似度）の算出を行う。

1. 原文 \(A\) および被験者 \(j\) （\(j = 1, \dots, n\)）が作成した文章 \(B_j\) を高次元ベクトルに変換する。
2. 両ベクトルのコサイン類似度（Cosine Similarity）を算出する。
   \[\text{Similarity}(A, B_j) = \frac{A \cdot B_j}{\Vert{}A\Vert{} \Vert{}B_j\Vert{}}\]
3. この類似度（0〜1の値）を「1回の伝達における生存確率 \(P(1)_j\)」と定義し、被験者 \(j\) における実質的な誤り率 \(r_j\) を以下のように近似・抽出する。
   \[r_j = 1 - \text{Similarity}(A, B_j)\]

## X.4 ベータ分布へのフィッティング（パラメータ推定）
実験によって得られた被験者全員分の誤り率のデータセット \(D = \{r_1, r_2, \dots, r_n\}\) （ただし \(0 \le r_j \le 1\)）を、第5章で導入したベータ分布 \(\text{Beta}(\alpha, \beta)\) の確率密度関数にフィッティングさせる。

パラメータの推定には最尤推定法（Maximum Likelihood Estimation: MLE）を用い、Pythonの統計ライブラリ（`scipy.stats.beta.fit`）を利用して、データに最も適合する形状パラメータ \(\alpha_{\text{estimated}}\) および \(\beta_{\text{estimated}}\) を逆算する。

### 実装アルゴリズム（Pythonによる方針）
```python
import numpy as np
import scipy.stats as stats

# 実験によって得られた各被験者の誤り率データ（例）
r_data = np.array([0.05, 0.12, 0.08, 0.22, 0.15, 0.03, 0.18, 0.09])

# ベータ分布へのフィッティング（範囲を0〜1に固定）
alpha_est, beta_est, _, _ = stats.beta.fit(r_data, floc=0, fscale=1)

print(f"実測値から推定された alpha: {alpha_est:.3f}")
print(f"実測値から推定された beta: {beta_est:.3f}")
```

## X.5 理論モデルへの適用と予測曲線の描画
得られた $\alpha_{\text{estimated}}$ と $\beta_{\text{estimated}}$ を、本研究で導出したベータ分布モデルの期待生存確率の解析解に代入する。
$$ P(N) = \frac{B(\alpha_{\text{estimated}}, \beta_{\text{estimated}} + N)}{B(\alpha_{\text{estimated}}, \beta_{\text{estimated}})} $$

これにより、「文字数を1.5倍に冗長化させながら情報を伝達していく社会空間」において、情報が $N$ 回伝搬した後にどの程度意味が保存されているかの劣化曲線を、完全に実測値ベースでグラフ化（検証）することが可能となる。

## X.6 期待される考察（ストーリー）
* **$\beta$ が大きく、分布が0付近に集中（シャープな分布）した場合**:
  医療統計の教育を受けた集団は、文章を引き延ばすよう要求されても、核となる論理やエビデンスの文脈を壊さずに論理的補足を行える高いリテラシー（生存能力）を持っていることを示す。固定の誤り率モデルよりも情報の半減期が劇的に伸びる。
* **分散（ばらつき）が非常に大きい分布になった場合**:
  専門教育を受けていても、個人の文章要約・生成能力の多様性（ヘテロジェニティ）により誤り率に大きな差が生まれる。この「誤りにくい優秀な伝達者のチェーン」が一定確率で存在することこそが、噂や情報が社会の中で奇跡的に原型を保って長生きする数理的要因（イェンセンの不等式効果）であることを実証できる。
